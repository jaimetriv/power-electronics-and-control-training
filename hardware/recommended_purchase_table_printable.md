# Recommended Purchase Table (Printable)

## Context

This printable list assumes you already own:

- OWON HDS272S
- ESP32 DevKit V1 boards
- 2 x Arduino Uno
- SparkFun Inventor's Kit
- SparkFun Beginner Parts Kit
- Inex Global POP-BOT kit
- Parallax BOE kit
- Parallax PING sensor

The table below focuses only on what is still worth buying for the training labs.
