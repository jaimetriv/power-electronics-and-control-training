# Power Electronics and Control Training

A practical hands-on course covering:

- Electronics Fundamentals
- PWM
- RC and RLC Circuits
- Control Systems
- Power Electronics
- Inverters
- System Identification
- Grid-Following VSCs
- Grid-Forming VSCs

## Recommended Hardware

### Controllers

- Arduino Uno
- ESP32 DevKit V1

### Test Equipment

- DSO Nano V3
- OWON HDS272S (optional upgrade)

### Power Electronics

- IRLZ44N MOSFETs
- IR2104 Drivers
- ACS712 Current Sensors

## Course Structure

### Foundations
